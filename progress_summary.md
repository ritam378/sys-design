## Interview Day Checklist

### Before the Interview
- [ ] Review RESHADED framework (Requirements, Estimation, Storage, High-level, API, Deep-dive, Extend, Discuss)
- [ ] Practice 2-3 capacity estimations
- [ ] Review your 3 strongest designs
- [ ] Prepare clarifying questions template

### During HLD Interview (45 min)
- [ ] **Minutes 0-5:** Clarify requirements, ask about scale, users, features
- [ ] **Minutes 5-10:** Back-of-envelope estimation (QPS, storage, bandwidth)
- [ ] **Minutes 10-15:** High-level design (draw boxes and arrows)
- [ ] **Minutes 15-35:** Deep dive into 2-3 components interviewer cares about
- [ ] **Minutes 35-40:** Bottlenecks, trade-offs, scaling considerations
- [ ] **Minutes 40-45:** Monitoring, security, edge cases, Q&A

### During LLD Interview (45 min)
- [ ] **Minutes 0-5:** Clarify requirements, core features vs nice-to-have
- [ ] **Minutes 5-10:** List main classes and their responsibilities
- [ ] **Minutes 10-20:** Define class relationships (inheritance, composition)
- [ ] **Minutes 20-35:** Implement 2-3 core methods with detailed code
- [ ] **Minutes 35-40:** Discuss design patterns used
- [ ] **Minutes 40-45:** Edge cases, thread safety, extensibility

## Self-Assessment & Practice Tips

### How to Know You're Ready
✅ You can explain any Must-Know problem in <40 minutes with clear diagrams
✅ You can handle "what if" questions about scaling 10x, 100x
✅ You can code LRU Cache from memory in <20 minutes
✅ You can estimate QPS, storage, bandwidth for any problem in <5 minutes
✅ You can discuss trade-offs for every design choice you make

### Practice Methods

**1. Whiteboard Practice (Most Important)**
- No computer, just whiteboard/paper
- Force yourself to draw clean diagrams
- Practice explaining while drawing

**2. The 5-Minute Pitch**
- Set timer for 5 minutes
- Explain entire high-level design
- Practice being concise yet complete

**3. Mock Interviews**
- Pramp.com (free peer practice)
- interviewing.io (paid, with real engineers)
- Practice with friends/colleagues

**4. Code Implementation**
- Implement LLD problems from scratch
- Use online IDE without autocomplete
- Time yourself (30-40 min per problem)

**5. Trade-off Flashcards**
- Create cards: "SQL vs NoSQL when?"
- "Redis vs Memcached when?"
- "WebSockets vs HTTP polling when?"
- Practice instant recall
